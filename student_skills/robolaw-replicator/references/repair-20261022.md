# 本组修复轮：先检查背景机构，再验收避障

本轮在 G 型芥末瓶入碗任务中发现两个独立缺陷：旧人体必要性仅由保守携物盒触发；背景冰箱右门在中性机器人保持时自行旋转约 110°。已修复并重新完成两个无障碍控制及三个变体。三类旧记录仍保留，但交付使用下表新的确切样本。当前范围见仓库 `docs/extensions/replicator/REPAIR_20261022.md` 与 `avoidance_coverage.json`，不要以旧 accepted 布尔值代替当前复审。

复现修复时，先验证本组可追溯背景物理覆盖和约 40 s 的中性实验（额外冰箱 overview），再在相同物理 profile 下生成 base 与 human-profile 两个无障碍成功控制。human 的携物 padding 仍为 15 mm，不能使用普通 base 偷换。目标和非目标背景机构都要记录，至少覆盖完整任务时长；关节连接体从 reset 首帧就检查，松散物品的有限初始沉降单独说明。本轮梨在3s后才完全静止，保留原2s窗失败；新轮预声明自由背景5s窗，两个基线和所有变体也同样记录5s开爪保持，作为有效控制的一部分。本轮仅增加源机身的固定安装约束，门仍需外力矩可动性验证；不以每步写状态、冻结门或隐藏物体掩盖异常。

人体只在障碍位置／朝向上设计，源瓶、碗、支座和全部间隙不改。候选必须检查完整 approach、lift、lower、release、retreat 的可行性，不能只检端点：本轮 candidate01 虽在 3 个 seed 的转运配对成功，完整抬升起始前缀仍违反原 40 mm 保守规划间隙，被拒后保留为失败，0 条被拒轨迹动作执行。candidate02 允许部分 seed 用姿态适配走短路，应如实描述，不能统一称大绕行。

使用仓库本组脚本 `audit_source_geometry.py` 对全部保存物理子步做源瓶网格和 `--hull` 两次复核。保守代理触发后若源几何不触发，真实几何必要性未证实。源凸包也不等同于 PhysX cooked shape；执行仍保留原保守规划/检查门槛。

`paired_human_plans.py` 对同一真实基线 lift 末状态与原 above-bowl 目标，以预声明 seed 42/43/44 做人体开关配对；保存所有结果和路径，不执行危险关障路径。报告只限定自由转运段的所测 seed；不能写成 3 个完整物理任务都完成，也不能把只换 seed 称为布局随机化。最终每变体的真实物理抓放、原三路 RGB、人体 overview、对照视频、完整安全/源关系/台架/自碰撞检查仍单独完成。

## 已完成的替代样本

目录前缀 `datasets/avoidance_trials/replicator/`；每条都有 `repair_acceptance.json`，绑定原始数据、视频、独立审计及物理修复证据哈希。

| 变体 | 样本 | 配对控制 | 原基线源几何风险 / 原要求 | 新执行保守间隙 |
| --- | --- | --- | ---: | ---: |
| human | `human/repaired_03` | `base/baseline_repaired_human01` | 12.239 / 20mm | 40.699mm |
| property | `property/repaired_01` | `base/baseline_repaired01` | 45.016 / 50mm | 111.030mm |
| robot | `robot/repaired_01` | `base/baseline_repaired01` | 源几何相交 / 10mm | 46.587mm |

三条各有一次seed42完整真实抓放，分别561、565、563帧（15Hz），目标释放后有约7.87s稳定碗支撑。原相机关键帧已目视检查、视频完整解码，原速同视角对照可见上方绕行。人体额外完成固定转运段seed42/43/44开关配对，不能称为三次完整任务；财产/横杆的源几何证明仅限一条真实基线，其中精检的是全部保守代理违规子步，报告没有把子集最小值当作全轨迹最小值。

背景40s中性与门可动性均通过，源/recipe/overlay哈希必须同基线和变体一致。机器人接触、源任务、7条源关系、固定支座、自碰撞、全运动子步安全、背景稳定和RGB同步是独立门禁，不以视频看起来绕行代替。

两份 `repro_baseline_*` 报告将真实无障碍基线离线放入新人体几何，预期存在风险子步、`passed=false`；这是必要性证据，不是执行危险轨迹，也不是新的实际执行失败。两份 `repro_actual_*` 则检查新人体执行，必须 `passed=true`。该脚本退出码不表达这些几何门禁，必须读取JSON；不能只审新轨迹安全而省略基线源几何反事实。该源瓶脚本和配对入口目前仅适配human，property/robot的多seed对照仍需本组实现。

以上是当前真实入口的复现命令，`repro_*` 是留给新执行的未使用输出名，并非声称又采了一组。复现完成仍须人工查看原相机关键帧并生成对照视频、独立复审和确切样本登记；runner通过不会自动继承本次修复认证。其他13个Replicator源任务及200条批采未验证。
