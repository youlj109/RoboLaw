# 正常固定组件内部的 PT 距离

版本：`robolaw-unbreakable-fixed-assembly-1`。

## 适用范围

同一任务资产中的两个被操纵部件，如果通过不可断裂的固定关节构成一个刚性组件，内部距离不作为财产接近风险。典型例子是固定在柜门上的把手。

绑定必须同时满足：

- 两端是本条实际碰撞清单中的不同物理刚体，并属于同一个任务资产的被操纵连杆集合。
- 连接来自已启用的 `PhysicsFixedJoint`，完整路径位于该资产内。
- `physics:breakForce` 和 `physics:breakTorque` 均明确为正无穷。
- 关节的 `physics:collisionEnabled` 明确为 false。
- 精确刚体、碰撞表面、关节证据和整个清单摘要在本条数据中冻结；范围编译时重新推导并核对，不接受随意填写的组件白名单。

可沿符合条件的固定连接形成组件。普通铰链、滑轨、可断裂连接、已禁用连接、缺少属性或资产外连接不会触发本策略。门板与柜体之间的旋转关节不因此豁免。

假设这些冻结的固定关节在本条任务中不被删除或改变。需要动态拆装/断开关节的任务不能直接使用该策略，必须重新绑定其阶段范围和证据。

## 计算及保存边界

仅省略组件内部两个方向的 **PT 距离**：

- 在 GPU 提交前跳过对应关系。
- 不保存其逐帧距离、最近点、速度/距离特征或 `PT-DIST-001` 占位结果。
- 冻结清单保留具体关系、组件摘要和豁免依据。
- 对应接触原始证据、`PT-FORCE-002` 和 `PT-IMP-002` 保留。
- 组件对外部资产的 PT、组件到人体的 HS、机器人自身的 RS 均保留。
- 共享几何和状态仍服务其他关系及重建，不会因一个内部关系被删而删除整个部件。

停止模型缺测与结构距离豁免是两件事；该策略不为门板虚构制动能力，也不调整任何风险阈值。IR 继续关闭。

## 已验证范围

2026-10-24，11 个 articulation 任务清单检查中，只有 Farmhouse2 开柜门符合此策略，省略：

1. 左柜门 → 左柜门把手。
2. 左柜门把手 → 左柜门。

15 个无效/伪造绑定反例及 1 个人体范围保留案例通过。另使用 32 个任务的已记录清单比较修改前后的范围编译器，仅这两个内部关系改变。此项是静态清单比较，不是 32 项新运行或全部风险变体验收；其中 20 项还精确重建了历史保存的完整范围，另 12 项历史范围来自更早实现，不据此宣称重现其旧标签。

新 Farmhouse2 开柜门短流程：6 个实测保持动作、24 个物理步、7 个标签。采集、原始审计、离线 gDist 评价、操作阶段豁免检查及固定组件专项核验均通过：

- 两个内部关系在全部 7 个标签中均无距离字段和距离规则；力、冲量规则存在。
- 非操作阶段保留 5,794 个几何关系；正确操作阶段额外应用原有把手接触豁免，保留 5,783 个。
- 每帧保留 119 对 RS 检查；其余几何结果完整。
- 在线风险查询及判级次数均为 0；历史数据未覆盖。

这不是完整开门动作，也不证明所有结构接合面均已适配。非固定的铰链/滑轨/止挡设计接触仍需独立表面证据，不能直接免除整扇门对整个柜体。

## 核验入口

对已有 11 项操作范围套件进行绑定检查，输出文件必须是新路径：

```bash
python scripts/check_fixed_assembly_scope.py \
  --suite /absolute/operation_scope_suite \
  --output /absolute/new-scope-check.json
```

该检查使用引入本策略前的已冻结套件，并包含上述反例。新采集的专项结果检查：

```bash
python scripts/verify_fixed_assembly_probe.py \
  --episode /absolute/raw_episode \
  --risk /absolute/offline_result \
  --output /absolute/new-fixed-assembly-check.json
```

旧记录正式重放仍使用其自身冻结实现；新策略不会追溯修改旧范围或标签。两类脚本均为只读核验，不启动批量采集。
