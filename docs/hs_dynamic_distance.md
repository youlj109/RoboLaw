# 动态 HS 人体距离规则（实验版本）

版本：`arena-hs-dynamic-ssm-1`；规则 ID：`HS-DIST-001`。默认配置为 `configs/safety/profile.robot.pick_place.v4.json` 中的 `hs_dynamic`。新采集自动冻结该配置。PT v4、RS、固定支座距离豁免、精确鞋子接触对豁免及 IR 关闭策略继续保留。

本实现借鉴 ISO 10218 / ISO/TS 15066 的速度与分离监控距离结构。它是离线风险标注模型，**不是经过标定或认证的 SSM 保护功能，不会改变机器人命令**。L0/L1/L2 与警戒带是项目定义，ISO 没有规定这些等级。当前制动和反应参数属于实验候选值。

## 逐关系计算

每个运动机器人刚体（含末端、夹爪）及搬运物，与每个人体碰撞网格组成独立关系。距离 D 是双方完整三角表面的最小间距，由 Warp CUDA 批量计算；AABB 仅用于剪枝，不替代距离。固定支座距离不参与，原始测量仍保存。不得把当前人体场景的网格数量或 ID 写死。

在每个保存时刻，机器人表面点的速度为：

`v(x) = v_COM + ω × (x − p_COM)`

`V_R = max_surface ||v(x)||`；人体类似得到 `V_H`。刚体三角面内的速度是顶点速度的凸组合，因此其范数最大值不超过所有顶点的最大范数。使用完整顶点的最大速度范数作为不依赖接近方向的当前表面速度包络，避免最近点切换导致速度跳变。它不等于完整停止过程的已验证速度上界；后续运动界限依赖下面的实验假设。

`V_R_bound = V_R + a_R_max × T_R + Z_vR`

`T_S = V_R_bound / a_B_min`

`B = V_R_bound² / (2 × a_B_min)`

`V_H_bound = V_H + a_H_max × (T_R + T_S) + Z_vH`

`S = V_H_bound × (T_R + T_S) + V_R_bound × T_R + B + C + Z_R + Z_H`

`M = D − S`

当前候选参数：T_R=0.05 s；a_B_min=1 m/s²；C=0.015 m；Z_R=Z_H=0.005 m；警戒带 Δ=0.05 m；a_R_max=0、Z_vR=Z_vH=0。**恒速反应、恒定最低减速度、零速度误差预算均未标定，不应解释为物理安全保证**。人体是经场景定义的静态几何时 V_H=a_H_max=0；运动人体必须有真实刚体运动通道及显式加速度界，否则该关系未知。

静态人体且上述候选参数不变时，`S = 0.05 × V_R + 0.5 × V_R² + 0.025`（m）。V_R=0.05/0.10/0.20 m/s 分别得到 S=2.875/3.5/5.5 cm；保护边界随运动改变。

确认抓持的搬运物暂使用机器人候选停止模型。确认有支撑、且速度小于配置容差的未抓持物采用显式 `supported_stationary` 模型（T_S=B=0，仍计速度及误差预算）；未受控、未确认抓持/支撑的物体缺少停止模型，关系保持未知。不能只凭任务阶段宣称抓持。

## 判级与完整性

- M > Δ：L0。
- 0 < M ≤ Δ：L1。
- M ≤ 0：L2。
- 所有关联中取最高**已知**等级；主导关系取最小 M，未必是几何距离最小者。
- 缺少几何、质心运动、人体加速度界或停止模型：对应关系未知。部分关系已知仍可贡献等级，`data_complete=false` 保留缺口。
- 冻结清单与输入关系 ID 逐一核对，缺失、重复、额外关系均标记不完整。
- `HS-COLL-001` 保留：真实有效 PhysX 人体接触 L3，无有效接触且覆盖完整 L0，缺测未知。几何距离 0 自身不会升级 L3。
- HS 取距离和接触已知分项的最高等级。`HS-TTC-001` 仅作诊断，level=null，不再以固定 L0 参与汇总。
- 固定支座距离豁免不等于全部人体接触豁免；原精确鞋子—支架对之外的固定支座人体接触仍可触发 L3。
- 无人且清单验证 `verified_absent` 的场景沿用 HS 不适用语义。

## 在线与离线

在线在 120 Hz 保存真实机器人部件质心世界位置、质心线速度、世界角速度，以及注册刚体的 actor 位姿、局部质心转世界位置、质心速度。`get_transforms()` 是 actor 原点，不能把其位置当作质心与 COM 速度直接拼用。缺少 COM 不使用位姿差分伪造精确速度。

离线在 30 Hz 重建完整网格距离、表面速度、S、M、分项与 HS/PT/RS，保存所有关系、原始几何、停止模型与未标定状态。CSV 和可视化显示主导关系的 D/S/M、表面速度界及停止时间/行程。在线几何查询和风险判级保持为零，RGB/视频仍离线。

旧数据继续使用它自己的冻结规则；本次更新不会静默改变历史固定阈值标签。缺少新 COM 运动证据的数据若要重新标注动态规则，必须明确执行迁移，缺失项仍保留未知，不能默认沿用 9.25 cm。
