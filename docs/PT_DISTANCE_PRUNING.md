# PT 远距离查询筛选

`configs/safety_observer_arena.json` 中的 `pt_v4_geometry.prune_outside_warning`
控制是否跳过远处关系的精确网格测距。设为 `false` 可恢复原来的全量精确查询。
物理碰撞体和 PT 资产清单不变。

每次采样更新姿态后，用完整机器人（或瓶子）与目标资产的整组 AABB
计算距离下界，扣除 0.1 mm 数值余量。只有下界严格大于该资产的 PT
预警外边界时才跳过精确查询。当前配置的外边界为 4 cm，代码从配置参数计算，
不按资产名称或某条轨迹的历史距离永久删除资产。

- 近处关系继续使用原来的 Warp 网格距离。
- 机器人到抓取目标的逐连杆距离始终保留，供抓持检测使用。
- 几何缺失时保留缺测状态，不能据此判断安全。
- 接触、力、冲量和掉落规则继续使用原有证据。

跳过查询的关系输出 `distance_status="lower_bound"`、`distance_m=null`，
下界放在 `distance_bound.lower_bound_m`。`coverage_complete=true` 表示有完整
的几何覆盖和下界证据，不表示测得了精确距离。消费端必须区分下界、精确值和缺测。
Arena 适配器依据原评估器实际输出的 `warning_outer_m` 再核对下界，
仅补全距离规则的 L0 结论；其他缺测原因不被清除。

摘要中的 `nearest_pair` 仅在能证明其小于所有跳过关系时给出；
`nearest_exact_pair` 仅代表已精确测量的关系中最近的一项。

验证：`tests/test_pt_pruning.py` 覆盖边界等号、阈值变化、无效证据、
机器人移近后恢复精确查询、抓持距离保留和最近资产摘要。
2026-10-22 的已保存抓放轨迹回放共 2292 帧：181,474 / 199,404 次关系查询
可跳过精确测距（91.01%），全部规则的等级、完整性和缺测列表与原记录一致。
另在五个姿态实际执行 CUDA 精确查询，保留距离与原记录差值为 0。
这不是整段仿真的耗时基准，也不证明资产在所有机械臂姿态下永久不可达。
