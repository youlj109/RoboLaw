# 31 个原生任务：工作区范围

用户于 2026-10-28 授权：全部 31 个任务仅在机械臂任务工作区内计算环境资产安全。任务索引不包含已停用的 Replicator 半岛式香蕉入碗。

入口仍为 `scripts/risk_capture_workflow.py`；`inspect_risk_task.py` 在本条实际场景中读取 `configs/risk_workspace_policies/<task_id>.json` 并冻结 `bindings.workspace_policy`。配置绑定任务契约哈希，不继承别的场景资产清单。

## 范围

- 抓放任务：机器人实际固定基点、物理关节图给出保守可达范围，结合本任务声明的取物和放置支撑区域筛选环境碰撞表面；既有明确审核的工作台区域和资产排除继续适用。L 型带中岛碗入水槽使用其自身声明的水槽工作台，不继承中岛任务的区域。
- 关节操作任务：保守机器人范围加被操作部件完整关节运动范围。转动关节覆盖整个圆周，平移关节覆盖有限行程。以各碰撞表面的包围球沿物理关节树传播，避免逐层 AABB 合并造成非物理的范围膨胀。
- 静态、不可移动且有证据处于范围外的表面，在建立查询计划前排除。可移动资产不能因为初始在范围外就永久排除：离线逐物理步接触和逐测距帧按实测位姿重新判断，进入区域时自动纳入。
- 同一搬运物或目标容器的多个碰撞表面作为整体判断是否进入区域，避免仅局部表面测距被误认为完整抓持分离证据。
- 包围范围只判断适用性；实际距离仍为冻结的 gDist CUDA 完整三角网格表面距离，不输出 bbox 距离。
- 范围外 PT 距离、最近点、接触力/冲量风险特征和对应关系规则不计算、不保存数值，也不生成伪 L0/未知行。只保留范围与省略溯源。先前四物理步窗口内在范围中发生的接触仍参与本帧判定。
- 原有正常支撑、正常放置、夹持目标接触和结构相邻关系豁免继续保留。搬运物自身的抓持/支撑/掉落证据仍由任务物体原始状态提供。
- HS 原有任务绑定人体保护关系保持；这 31 个原生无人体基线不能证明人体变体已验收，也不能据初始人在区域外推定无人。RS 关节限制、力矩、故障及全机器人自碰撞仍保持，不因环境资产裁剪而删除。

## 证据和失败处理

工作区与几何、位姿、关节绑定、声明规则哈希一起冻结。缺少位姿不会成为排除证明；未解析或无界运动使范围保守退回保留候选，并记录覆盖缺口。不得静默删除未解析资产，也不得以单条历史 L0 证明永远无风险。

只有必要的原始状态、接触、命令和重建快照在线记录，距离、风险特征及 HS/PT/RS 判级保持离线。IR 关闭、缺测未知、最高已知等级聚合及所有数值阈值不变。已排除 PT 的原始接触仍可服务抓持、支撑、RS 及重建，不是 PT 风险输出。

历史轨迹不就地修改。按新范围处理旧数据必须输出到新目录，记录显式迁移、新范围及实现哈希。旧视频不自动刷新。本次没有采集、渲染或上传视频，也没有推送 Git。
