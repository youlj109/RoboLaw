# HS 数据计算与保存排除

2026-10-23 用户逐项查看 HS 资产后，明确要求移除人体休闲服、固定底座和支座的相关计算及保存。

## 配置与生效边界

配置为 `configs/safety_observer_arena.json` 的 `hs_scopes.data_omissions`，版本 `arena-hs-data-omission-1`。实现按每条数据的环境根、人体根和固定刚体身份解析，不在采集入口硬编码场景 ID。

- 人体休闲服：`person/Visual_KitchenAdult_male_casualsuit01/male_casualsuit01_001`。
- 固定底座及支座：刚体 `panda_link0`，包括其底座和支架碰撞几何。随动夹爪基体 `base_link` 保留。
- 碰撞表面在构建 HS 网格/BVH 之前被跳过，不进入 HS 冻结几何清单、合并最小距离或逐关系动态查询。
- 接触采集按冻结身份，在读取点位置、法线、冲量和分离量之前跳过休闲服相关接触，以及固定底座/支座与人体的接触。未识别的接触身份不自动排除。
- 不保存对应 HS 距离、最近点、表面速度、TTC、接触点、固定分项等级、固定原始相交记录或支座场景摆放审计。排除策略只作为配置/溯源保存，不伪装为 L0 或缺测。

## 当前剩余 HS 范围

17 个机器人运动部件及芥末瓶，对人体剩余 5 个网格分别测距：身体基础、短裤、眉毛、鞋子、`high_poly`。逐关系动态距离清单从 108 项变为 90 项；这不是 GPU 核函数数量，也不代表耗时同比例下降。

固定底座/支座此前已豁免动态距离判级，本轮进一步停止其 HS 审计查询与保存；人体休闲服对应的 18 项动态距离关系也停止。其他规则仍基于保留下来的有效证据，IR 关闭，缺测保留未知。

## 共享证据与历史数据

HS 与 RS 不再共享被裁剪的机器人几何。RS 独立冻结、重建完整机器人碰撞几何，继续其既有自碰撞范围；PT 继续自己的资产关系。为 RS/PT、控制和场景重建所需的机器人状态、共享几何及原始 USD/渲染快照仍按各自用途保留。没有修改物理碰撞体、外观、驱动或规划输入。

新数据在 binding/profile 中冻结 HS 排除策略及 RS 独立几何身份，原始采集状态仍为 `pending_offline`，离线结果为 `offline_replay`。离线加载器以冻结标志选择 HS/RS 几何，缺少新标志的历史归档继续原有路径，不自动套用本轮排除。本轮不删除历史数据。
