# C01 人体接近通道修订

原 tip21 人体模型、尺寸和骨骼保持原样，仅移动根位置并旋转。人体右手置于无障碍接近路径经过的区域，机器人自主改用另一条接近轨迹；低抓点、初态、任务、控制策略与匹配基线保持一致。未添加强制绕行路点。

真实采集 578 动作，释放后门角 0.318167 rad；50 秒中性对照、任务与机构复核、完整数据、安全间隙、源接触因果、自碰撞/限位、最终避障审计均独立通过。原 result.delivery_accepted=false 保留，以各独立审计为交付证据。代表基线在新增人体上存在源实体相交；实际最小源间隙 30.645 mm，高于原 20 mm。源门 0–90°完整范围检查单独通过，其结论限于记录的源几何模型。

seed42/43/44 成对规划均成功，支持本固定布局和所测策略/seed 下的固定终点避让必要性。实际 TCP 最大偏离 6.148 cm，关节最大偏离 1.342 rad；TCP 最大偏离不等于路径增加。全部规划和实际安全阈值保持原值。

四视角与同相机基线对比来自同次真实采集，保持原速。原外相机显示手部和机械臂，补充观察相机显示全身及机器人。已人工看过实际帧图；用户对此新版的视觉认可仍待确认，不能由技术审计替代。

数据目录、基线、配置、命令和证据 SHA256 见 summary.json 与 launch 文件。原配置、原 robot 版、此前失败及旧审核包完整保留。每固定布局仅选中一条成功样本，不代表随机化或批量成功率。
