# Source-space diagnostics and Cartesian endpoint posture discovery

The previous discovery requires the old baseline pregrasp endpoint and all sampled later baseline robot postures to stay clear. Those are useful conservative screens, but the task fixes the source Cartesian handle/TCP target, not the redundant elbow joint solution. Existing paired planning and actual avoidance audits already validate the new measured endpoint against that same Cartesian target. The v24 optional --allow-endpoint-posture-adaptation therefore keeps the original initial-state, support and full sampled moving-door/environment source checks, while delegating the new endpoint and later arm posture to unchanged independent on-planning and actual 120 Hz acceptance. It forbids simultaneously constraining historical approach/endpoint posture references. Default behavior remains the prior conservative discovery. The original safety margins and final delivery gates are unchanged.

These are not accepted variants: each still needs all three paired seeds, actual source intersections, a small safe reroute and a real successful collection plus neutral/contact/audit/video evidence. These finite samples neither prove impossibility nor constrain feasible new redundant IK poses. Door rejection reports stop at their first failing pair/sample; a near-threshold first failure is not the worst clearance over the whole sweep.
