## 最终证据清单

本组 manifest 必须绑定实际源 YAML、资产清单、配置/实现源码，以及每条 episode 的原始轨迹、RGB、接触、物理/背景状态、startup 原始记录、原相机视频及审查报告。无障碍控制、变体、neutral 和 mobility 的物理 profile 必须匹配。各类门禁分别保留，任一缺失或失败都应显示为未完成。

startup gate 复算每个子步的稳定性，核对真实关节/刚体映射、关节端点、经过证明的 articulation root alias 和静态 anchor 源位姿；检查 8 个 warmup 与完整初始保持阶段，以及侧车与 HDF5 动作前后状态、相机物理步、后续物理记录的连续交接。prefix FCL 仍是采集器当时保存的检查证据，汇总器核验完整样本数和源码快照，不声称重新执行了几何仿真。源码在采集前后必须一致，后续编辑不能改写该快照。

另以 `absolute_motion_and_provenance` 门禁复算 `motion_physics_index.npz` 的绝对物理步，要求主记录首步紧接 startup 尾步、逐行绑定原 `physics_states.npz` 的 phase/action，且末步等于真实采集结束计数；`collection_provenance.json` 绑定执行源码快照和实际 source/recipe/overlay、输入配置的采集前后哈希。旧 `_01` 与失败 `base02` 没有这些新侧车，不能事后补造。源码后来发生合法修改时，比较已归档快照及当时首尾哈希，不能拿当前工作树冒充当时执行版本。

最终源几何检查也必须包含真实 startup 和主轨迹两个区间。manifest 核对 `startup_rows` 的绝对物理步/阶段、主轨迹逐行 action/phase、两段总样本数、侧车哈希、原始安全距离和统计重算。安全执行须两个区间在源 mesh、源 hull、保守执行模型中均通过；避障必要性仍须在任务运动段出现源几何风险，不能只用 startup 的风险声称规划必要性。这里不重跑 FCL，距离本身仍由绑定源码和资产的独立审计产生。

人工/Agent 实际查看后单独写视觉报告，至少包含具体观察、确切 episode、相机、帧索引、抽样范围，以及对应原始 HDF5、montage/比较视频的 SHA256。生成 montage 或完整解码不能自动生成视觉通过。
