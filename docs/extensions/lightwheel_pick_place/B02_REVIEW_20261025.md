  was 0.07572 m against the original 0.02 m execution margin. A separate fixed
  base audit also found the person's shoe intersected the robot stand.

  root z was about 0.00574 m, versus the authored 0.922 m countertop placement.
  It had fallen to the floor before the recorded rollout. Later stability alone
  does not establish a valid supported initial layout.
- The old robot rollout's barrier base overlapped the source plate. Measured
  plate initial position differed from the baseline by 5.225 mm and orientation
  by 4.630 degrees, beyond the existing 1 mm / 1 degree comparison limits.

These findings do not negate physical fruit placement, but prevent full safety
augmentation acceptance. No distance or initial-state tolerance was relaxed.

paired the first phase state with the last goal. It also applied vertical-column
planning to the shelf's MotionGen approach. `--recorded-plan-index` now selects
an individual executed leg, its exact target, measured starting frame and method.
Frame offsets include the collector's 12 hold frames and fail on count mismatch.
All baseline approach/lift/transfer counts were checked: 175 / 351 / 154 frames.

Source-support, fixed-base and source-background auditors are parameterized for
the task. Source support tests the finite collider's height slab: a fruit safely
below an elevated shelf is not treated as touching an infinite downward plane.
The original rest tolerance, 50 mm contact region, permanent detach latch and
full-world collision gate remain unchanged. Original reports are preserved as
`source_support_audit.before_shelf_slab_fix.json`; four shelf rechecks passed.
All four old episodes also passed independent self-collision/limits audits.

Later banana tuning changed the shared IK residual from .001 to .004 and changed
shelf-style approach choices. B02 now uses an owned `LemonKinematics` adapter
retaining .001, the baseline .17 m local pregrasp and original MotionGen approach.
The shared and banana modules are not modified by this correction. Avoidance
control matching now additionally checks these recorded settings, lower policy
and executed planning-method sequence.
