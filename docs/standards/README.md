第一份规定目录、字段、单位、时钟、适用性和未知值、特征与等级记录、JSON 示例、媒体溯源及当前仓库映射。`robot-risk-exchange-1` 是本次文档定义的通用交换契约；现有仓库使用自己的实际 schema，由有版本的适配器映射，不表示全部新字段已经原生实现。

第二份规定每步必须在线保存的原始状态、接触、实际命令和重建快照，以及离线完整网格 gDist、风险特征、HS/PT/RS、RGB 和视频流程。默认参考频率为 120 Hz 物理、30 Hz 动作及离线标签；其他频率须显式版本化。

每个新任务建立自己的资产、正常任务关系、几何、随机化边界和规则绑定。IR 关闭，缺测保留未知。人体芥末瓶案例不能替代开门、抽屉或其他新任务的实测验收。视频和采集原始数据不随文档上传 Git。
