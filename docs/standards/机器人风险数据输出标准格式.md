# 机器人风险数据输出标准格式

通用实施规范  第1版  2026年10月23日

本文件规定一次机器人任务从原始证据到 HS 人体安全、PT 财产安全、RS 机器人本体安全及视频的交付格式。用于其他 agent 实现读取器、采集适配器、离线评价器和数据检查器，覆盖 pick-and-place、开门及抽屉等 articulation 任务。

### 1 规范的适用方式

本文件定义通用交换契约 robot-risk-exchange-1。它是本次提出的规范层，不表示现有仓库已原生实现全部字段。现有文件可保留，通过带版本的适配器建立字段映射；未支持字段必须明确缺测，不能改名伪装已实现。示例均为格式示意，不是新增采集结果。

“必须”表示缺少便不能宣称相应结果可复现；“条件必须”表示只在某规则或任务适用时要求。原始证据不可覆盖。IR 关闭。在线只保存必需证据，风险距离、特征、判级、审计、RGB 和视频离线生成。

### 2 通用逻辑目录

```
dataset/<run_id>/<episode_id>/
  manifest.json                 # 身份 版本 文件索引
  frozen/                      # 任务 角色 几何 规则 相机
  raw/                         # 原始状态 命令 接触 事件
  checks/raw_integrity.json     # 数量 哈希 覆盖和失败
  derived/<evaluation_id>/      # 离线特征 判级 诊断
  media/<render_id>/            # RGB 帧索引 视频及来源
```

这是逻辑目录，允许物理存储采用 HDF5、NPZ 或分片。manifest 必须列出逻辑数据集到实际文件及数组的映射。多个环境分别有 episode_id；仿真重置或失败重试使用新的 attempt_id，禁止拼接为同一连续轨迹。

### 3 交付状态

| 阶段 | 必需状态与含义 |
| --- | --- |
| 原始采集 | capture_status=complete 且 evaluation_status=pending_offline；采集成功不代表已判级 |
| 离线评价 | evaluation_status=offline_replay；另列执行成功、几何覆盖、各类别证据完整性 |
| 媒体完成 | 记录 media_status 及来源 evaluation_id；任务成功与视频成功单独报告 |
| 失败或缺测 | 记录 partial 或 failed、错误码、缺失通道和源步范围；不得冒称完整完成 |

## 4 身份 几何与范围清单

### 4 1 清单字段

| 字段组 | 必须保存的内容 |
| --- | --- |
| 身份 | schema_version、run_id、episode_id、attempt_id、env_id、task_id、scene_id、robot_ids、创建时间 |
| 复现 | 任务配置和随机种子、实际随机化结果与允许范围、引擎及依赖版本、源码与未提交差异摘要 |
| 时钟 | physics_hz、observation_hz、decision_hz、窗口步数、初始化序号、动作与观测因果顺序 |
| 坐标与单位 | 世界坐标约定、重力方向、长度 m、时间 s、角度 rad、四元数 xyzw、矩阵存储次序 |
| 冻结摘要 | task_hash、scope_hash、rules_hash、profile_hash、geometry_manifest_hash、backend_build_hash |
| 文件索引 | 相对路径、字节数、SHA-256、格式版本、数组形状和类型、记录数、首末源步、写入完成标志 |

文件 SHA-256 对最终字节计算。配置语义摘要必须声明规范化算法；若无统一算法，直接冻结 UTF-8 文件字节并计算摘要。浮点显示精度不能改变判级输入。所有引用的冻结文件必须随数据可取得，不能只留主机绝对路径。

### 4 2 资产与几何

每个 asset_id 绑定完整 prim、actor、link、collider 路径，角色、刚体或关节属性及所属机器人或人体。geometry_id 绑定 vertices[Nv,3]、faces[Nt,3]、单位、拓扑与内容哈希；索引合法且使用零基。缩放和剪切必须烘焙进几何或以明确可重建的仿射链保存。每个实例绑定局部变换和动态刚体。曲面三角化误差及分辨率单独记录。

### 4 3 关系与省略

每个 relation_id 记录 source_id、target_id、category、rule_ids、active_phases、query_distance、persist_distance、evidence_only、grade_distance、grade_contact、grade_force、grade_impulse，以及 reason、authorization、guards 和策略摘要。acquisition_omission 另列，不能由距离排除自动推导。

query_distance=false 的关系不生成逐帧距离字段、距离规则或伪 L0；在冻结清单记录一次即可。必要抓持测距可设置 query_distance=true、evidence_only=true、grade_distance=false。正常放入容器、预期支撑接触按任务角色绑定，不按“碗”“桌子”等名称作全局排除。

## 5 原始运动数据格式

所有数据记录源物理步和仿真时间。参考设置是 120 Hz 物理、30 Hz 动作观测、30 Hz 离线标签。刚体通道包括机器人、搬运物、受保护人体和关节资产各活动连杆；适用通道不得只保存末端或根节点。

| 数据集或字段 | 形状与类型 | 约束 |
| --- | --- | --- |
| source_physics_step | int64 标量 | 严格递增；初始化单独标识 |
| sim_time_s | float64 标量 | 与物理时钟映射一致 |
| body_ids | string[B] | 稳定 ID 到数组行索引 |
| position_world_m | float[B,3] | 实际 actor 原点位置 |
| orientation_world_xyzw | float[B,4] | 有限且合法单位四元数 |
| com_position_world_m | float[B,3] | 世界 COM 位置，不能用 actor 原点替代 |
| com_linear_velocity_world_mps | float[B,3] | 实际 COM 线速度 |
| angular_velocity_world_radps | float[B,3] | 世界角速度 |
| joint_ids | string[J] | 受控机器人与外部关节分别绑定 |
| q dq applied_effort | float[J] 各一组 | 转动 rad、rad/s、N·m；移动 m、m/s、N；逐关节声明 |
| limits 与 effort_limits | 冻结数组或时变数组 | 单位、来源、适用关节及时间 |
| validity 与 missing | 掩码和原因 | 按实体和通道给出，不能只用全帧有效 |

### 5 1 状态重建

每物理步必须能恢复所有纳入几何的世界位置。关节资产保存逐连杆位姿及运动，或保存能精确恢复它们的实际 joint 状态和冻结运动学。只有 30 Hz 渲染位姿不能自动满足任意 articulation 的 120 Hz 原始运动要求。形变人体需逐时刻顶点，或足以恢复顶点和表面速度的骨骼及 skinning 数据；刚体通道不足时明确未支持。

转动与移动关节分开标注 joint_type 和单位。外部抽屉的 m 与 N 不能填入机器人 rad 与 N·m 字段；当前 RS 的 1 度限位预算不直接适用于移动关节，新增适用性须显式定义。

### 5 2 非有限值

JSON 禁止 NaN 与 Infinity；无效标量输出 null 并写原因。二进制数组必须配套有效性掩码；若内部使用 NaN 哨兵，不能被当作测量传给评价器，交换记录必须转 null。未测量、未加载、不适用与实际测得零不能合并。

## 6 原始接触 命令与事件

### 6 1 接触事件字段

| 字段 | 要求 |
| --- | --- |
| 事件身份 | event_id、episode_id、source_physics_step、sim_time_s、事件类型 |
| 两端身份 | body0_id/body1_id、collider0_id/collider1_id；路径映射必须可解引用 |
| 接触点 | world_position_m[3]、normal_world[3]、impulse_world_Ns[3]、separation_m |
| 方向语义 | 说明法向和冲量作用于哪一端；交换两端时向量符号一致处理 |
| 覆盖 | 订阅的对象和事件范围、起止步、订阅或缓冲错误、完整性标记 |
| 空事件 | 只有覆盖完整的物理步无报告，才可推导该范围没有接触 |

接触力若未直接提供，在线不从冲量计算风险力。离线 PT 使用同一 body pair 每物理步净冲量向量范数，再在四步窗口取最大；保留原始点及方向以复现。距离-only 排除不删除仍供力、冲量、抓持或掉落使用的原始接触。

### 6 2 动作和观测

每条实际命令记录 command_id、action_index、调用次序、命令类型、目标实体、实际提交参数及单位、提交时刻、对应动作前 observation_id、写入返回或异常。规划目标与实际命令分别存储；命令力矩不能充当实际施加力矩。动作前观测引用该命令之前已完成的源物理步。

### 6 3 故障与任务原始信号

故障流保存故障码、权威来源、首次及恢复时刻、关联关节和遥测覆盖。没有异常日志不等于权威故障通道正常。命令写异常和无效遥测可作为已观察事件，但必须与权威驱动故障状态区分。保存手指实际关节、手物位姿和原始任务阶段信号；held、supported、drop 为离线推断结果。

### 6 4 时间窗口

每个标签包含 window_start_step、window_end_step、expected_steps、observed_steps 及 source_physics_step。窗口应为四个连续物理步且无重叠或漏步的解释歧义。初始化若不足四步，记录不完整，不能补零接触。评价完成时间使用独立 wall_time，不替换源时间。改变频率或窗口必须另立版本。

## 7 离线风险特征输出

features.jsonl 是可完整表达嵌套状态的主记录；risk_features.csv 是扁平查看副本，不替代原始证据和规则记录。每条特征绑定 episode_id、evaluation_id、source_physics_step、relation_id、单位、validity、source_refs、scope_hash 和 profile_hash。

| 类别 | 应输出的特征及相关规则 |
| --- | --- |
| HS 距离 | 完整表面距离 D、来源、两端碰撞体身份、各端表面速度、停止模型、反应及制动项、保护距离 S、裕量 M、主导关系；HS-DIST-001 |
| HS 接触与诊断 | 有效人体接触、覆盖和事件引用；HS-COLL-001。距离差分接近速度、TTC 仅诊断；HS-TTC-001 |
| PT 距离 | 有效关系距离、适用性、抓持与支撑状态、S_PT、警戒外边界、最近有效距离及关系；PT-DIST-001 |
| PT 冲击 | 逐步净冲量及四步最大值、dt、力代理值、统计标识、材料代理限值与不确定性；PT-FORCE-002、PT-IMP-002 |
| PT 掉落与审计 | 掉落事件、实测下降速度与高度、阈值来源；PT-DROP-001。支撑裕量 PT-SUP-001 和损伤 PT-DMG-001 当前 audit_only |
| RS 关节 | 实际力矩、额定限矩、最大比值、不确定性；RS-TORQ-001。限位最小裕量、主导关节和不确定性；RS-JOINT-001 |
| RS 碰撞与故障 | 完整机器人自碰撞对、结构白名单与覆盖；RS-SELF-001。故障身份、故障后实际运动、锚点与覆盖；RS-FAULT-001 |

### 7 1 几何结果的固定口径

使用冻结 gDist 的完整 authored 碰撞三角表面，FP32 无符号最小距离；不是解析曲面距离或穿透深度。metric=gdist_authored_collision_surface_distance。源标识保留 link_target_gdist_surface_distance_gt 或 pt_environment_gdist_surface_distance_gt 等实际来源，适配器不能伪造来源门槛。

当前桥接没有导出最近点坐标：nearest_points_world_m=null、nearest_points_valid=false。不能用零坐标、bbox 最近点或任意顶点画“真实距离线”。几何距离为零不能单独证明 PhysX 人体接触，表面包含也不能被宣传为完整实体碰撞检测。

## 8 等级 状态与证据记录

| 字段 | 类型与语义 |
| --- | --- |
| rule_id relation_id category | 字符串；类别 HS/PT/RS；关系型规则必须有唯一关系 |
| level | L0/L1/L2/L3 或 null；按已知结果聚合，不用字符串“未知”作大小比较 |
| complete missing | 布尔及缺测原因数组；等级已知也可能 complete=false |
| evaluation_status | evaluated、partial_known_results、not_applicable、audit_only 或 diagnostic_only |
| evidence source_refs | 结构化证据值与原始记录引用，包含文件和源步或记录 ID |
| 版本与摘要 | rules_version、profile_hash、scope_hash、geometry_manifest_hash、backend_build_hash |
| source_level | 条件字段；兼容源值与最终活动判级不一致时保留原值和解释 |

### 8 1 聚合与完整性

类别等级取其活动规则已知等级的最大值，没有有效已知结果则为 null。已知 L2 或 L3 不因其他缺测丢失；L0 也不代表所有证据完整。类别与整体必须同时给 level、data_complete、missing、known_rule_count、required_rule_count 及适用性。几何全量与类别证据完整分别报告。

### 8 2 特殊状态

明确省略项只在范围清单中标 omitted_by_policy，不生成逐帧空距离或伪 L0。IR disabled 且 level=null，不参与活动类别覆盖。HS-TTC 只诊断；PT-SUP 和 PT-DMG 仅审计，最终 level=null，不参与等级。

当前无人兼容行为可能输出 HS=L0、status=not_applicable；必须同时保留该状态和 verified_absent 的闭世界证据，不称为已测得人体安全。现有整体聚合可能包含此兼容值，应保存 source_level 与 aggregation_version，不能在导出时静默改历史结果。

未抓持物距离、完全抓持豁免和已证实支撑距离在部分源路径返回兼容 L0，但不进入最近有效距离。最近有效距离为空时输出 null 和原因，不输出 0。compatibility 状态必须保留，防止统计时把不适用项计为真实安全样本。

### 8 3 规则稳定性

HS 使用动态表面速度与关系独立保护边界；PT 使用 v4；RS 使用冻结的力矩、限位、自碰撞和故障后运动规则。边界、容差和事件统计以第三份 Skill 的冻结实现为准。仅运行基础评价器，不应用动态 HS 和 Arena 适用性及已知结果聚合，不能声称结果等价。

## 10 媒体 性能与错误输出

### 10 1 视频与帧索引

视频建议 MP4 H.264，参考 30 fps，画面尺寸、像素格式、编码参数和实际帧数写入媒体 manifest。实际视角数不固定；每个 camera_id 绑定内外参、相机状态和 RGB 来源。视频画面、等级与原因必须来自同一 episode 和 evaluation_id。

| 帧索引字段 | 要求 |
| --- | --- |
| frame_id video_pts_s | 显示帧序号与视频时间；不能代替源仿真时间 |
| source_physics_step sim_time_s | 本帧测量场景来源；相机和物体状态可追溯 |
| decision_source_step | 采用源时间不晚于 RGB 的最近有效标签；无标签则显示待评价或未知 |
| camera_ids render_id | 视角身份和冻结相机摘要；离线重建来源标记 |
| evaluation_id decision_ref | 精确链接当前离线规则与证据；不得引用旧视频的标签 |

不在视频显示已省略项；可显示 HS/PT/RS 等级和主导依据。视频仅保存远端和本地，不上传 Git 或魔搭。离线渲染不能冒充真实在线视觉策略输入；如策略实际依赖在线 RGB，则原始在线图像属于必须保存的输入证据。

### 10 2 性能数据

performance.json 必须区分模拟时长与物理耗时。按阶段记录启动初始化、采集、写盘排空、原始校验、解码、BVH 构建、暖态 geometry、特征、规则、序列化、渲染、视频及总墙钟时间；并标明计时范围、计时器和是否嵌套，禁止把重叠阶段相加当总耗时。

可附风险时刻耗时 p50/p95、关系数量、三角形数量、显存峰值、缓存命中、失败数与 GPU 利用率。比较后端时固定原始轨迹、关系集合、频率及精度；GPU 利用率不是准确性或端到端速度证明。

### 10 3 错误与迁移

错误记录包含 stage、error_code、实体或关系、源步范围、missing_channel、是否可重试、软件版本和日志引用。文件损坏、缺步、未知身份、哈希不符不得填零继续。后端不可用不自动切换 Warp/FCL/bbox；标未知或明确失败。显式重算保存新 evaluation_id、原始数据摘要、旧新规则和后端身份及迁移原因，不能覆盖历史派生结果。
