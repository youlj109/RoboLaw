# 机器人原始数据采集与离线安全评估规范

通用实施规范  第1版  2026年10月23日

本文件说明如何采集可复现的机器人任务证据，再离线提取风险特征、评估 HS/PT/RS 并生成视频。采集器必须记录实际发生的状态与事件；可离线工作均在采集后完成，以缩短在线过程并保持风险结果可追溯。

### 1 采集边界

| 在线必须完成 | 离线完成 |
| --- | --- |
| 任务执行所需物理、规划和控制 | 风险距离、最近关系与几何风险查询 |
| 实际状态、COM 运动、关节遥测 | 表面速度、动态保护距离、TTC 和风险特征 |
| 原始接触、命令、故障和覆盖 | 抓持、支撑、掉落推断及 HS/PT/RS 判级 |
| CPU 网格、规则、场景和渲染快照 | 风险 GPU BVH、gDist、完整审计、RGB 和视频 |

控制器为执行任务必需的碰撞规划仍可在线运行，必须与风险采集器分开记账。不能声称关闭了物理碰撞，也不能借用规划调用在线附带计算风险等级。若视觉策略实际需要在线相机输入，其原始输入必须在线保存。

### 2 阶段和通过条件

准备任务 → 冻结清单 → 在线 raw-only → 排空与完整性校验 → 离线 gDist 和特征 → 冻结规则判级 → 同源状态 RGB 重建 → 视频及交付。IR 保持关闭，缺测保留未知。

capture 完成后停在 pending_offline，不自动开始评价。evaluate 输出 offline_replay。任务是否成功、原始证据是否齐全、规则是否给出等级、风险证据是否完整分别报告；任何一项不能替代其他项。

### 3 跨任务适用范围

按 engine_adapter → raw_episode → offline_features → frozen_rules → media 实现。任务和实体来自每条 episode 的角色映射，不固定人体芥末瓶场景 ID、资产名称或数量。新任务必须完成本任务验证，不能将接口可运行直接宣称完整支持。

## 4 建立本任务资产与关系

### 4 1 潜在碰撞范围

枚举机器人所有活动表面、夹爪、搬运物外伸、被驱动面板或抽屉、人体及其他保护资产。候选范围覆盖完整动作、撤回、夹爪张合、误差和允许随机化。无法证明不接近风险区域的关系保留。历史几次 L0、初始很远或名称相同都不能证明可以删除。

允许在准备阶段用保守可达包络选择候选，或在离线用完整轨迹与误差包络筛选。用于接近等级时，包络必须扩张到保护距离和警戒范围，不能只证明不会接触。AABB/BVH 只作保守剪枝；其下界不得保存为真实风险距离。用户明确缩小范围应写为范围决策，不夸大为物理不可能。

### 4 2 正常任务关系

| 任务关系 | 推荐绑定及限制 |
| --- | --- |
| 物体放入目标容器 | 物体到目标容器的正常接近距离不判 PT；是否排除其他 PT 分项单独声明 |
| 物体落到预期支撑面 | 按阶段和支撑角色排除不合理距离判级；不能自动免除损伤或冲击 |
| 夹爪与被抓物 | 精确抓持部件可豁免距离判级；需要抓持证据时保留必要几何或原始接触 |
| 操作把手或关节配合面 | 只豁免设计接触部位和阶段；不排除整条机械臂对整个柜体 |
| 其他机器人或资产 | 按本任务实际潜在关系纳入；不沿用厨房资产白名单 |

### 4 3 HS 数据移除与共享通道

真正固定的支座按关节图和刚体身份确定，不能按 base_link 字符串删除。仅对本任务明确授权的固定结构或衣物实施 HS acquisition_omission；检查剩余人体表面是否存在覆盖缺口。HS 删除不破坏 RS 完整机器人自碰撞、PT 证据及共享重建状态。

冻结 query_distance、persist_distance、evidence_only 和各分项 grade 开关。完全不计算必须在建立离线队列前过滤，不能先算后隐藏。随机化改变角色、几何、运动范围或清单 guard 时重新解析。

## 5 任务适配和冻结准备

| 任务或对象 | 采集前必须落实 |
| --- | --- |
| 其他 pick-and-place | 全部 payload、目标容器、支撑面、夹爪部件和真实开闭方向；逐物体抓持状态和停止模型 |
| 开门和抽屉 | 各活动连杆位姿及 COM 运动；joint 类型、轴、父子、q/dq、限位、驱动目标和实际力矩若存在 |
| 被驱动面板靠近人体 | 面板作为 HS 运动源；机械耦合和停止模型另绑，不能直接认作 held payload |
| 动态人体 | 真实运动及加速度界；当前参考动态人体加速度界为空，未补齐时相应规则未知 |
| 形变人体或软体 | 每时刻可重建几何和表面速度；旧刚体通道不足，未实现则明确未支持 |
| 移动底盘或新机器人 | 重新建立运动部件、限位限矩、结构相邻白名单；移动基座不作固定豁免 |

### 5 1 冻结内容

每条数据冻结任务与随机化实参、角色关系图、完整网格、拓扑、仿射变换、动态路径映射、关节图、相机内外参、灯光材料、物理设置、规则与 profile、有效包装链、后端身份及构建摘要。网格路径不能代替网格内容，存在未提交代码时保存实际快照摘要，不用 Git 提交号冒充全部运行源码。

### 5 2 采集前检查

确认原始证据通道能覆盖全部适用规则；COM 位置与 COM 线速度来自同一实体和源时刻；实际力矩与控制命令分开；接触订阅覆盖可检查；渲染快照能重建本任务。CPU 冻结期间不建立风险 GPU BVH。确认写盘目录、空间、权限及写入器可用，再开始物理循环。

若能力不足，先记录具体缺口并决定补齐通道或接受明确未知。不能用阶段、计划轨迹、静态初始位姿或其他场景的阈值充当本任务实测证据。

## 6 在线原始采集实施

### 6 1 源频率和读取时机

参考物理步长为 1/120 s；每个已完成物理步读取实际位姿、COM、关节遥测、接触与事件。动作和动作前观测 30 Hz；离线风险标签 30 Hz，每个标签含连续四步接触窗口。初始状态使用明确初始序号，不能伪造已完成接触窗口。

| 在线数据 | 保存要求与禁止替代 |
| --- | --- |
| 刚体运动 | 每活动实体的 actor 位姿、世界 COM、COM 线速度和世界角速度；不能只存 TCP |
| 机器人关节 | q/dq、实际施加力矩、身份顺序、限位和限矩来源；不能以目标力矩代替 |
| 逐步接触 | 两端 actor/collider、接触点、法向、冲量向量和分离量，以及订阅覆盖 |
| 实际命令 | 实际写入的命令及调用顺序、动作前观测、提交时刻和异常；规划值另存 |
| 抓持与物体 | 手指关节、手物相对运动所需位姿、payload 位置速度及原始接触；在线不判 held/drop |
| 故障与渲染 | 故障来源和覆盖、实际错误事件；可重建的相机、场景和活动连杆状态 |

### 6 2 异步写盘

使用有界队列和独立 writer。读取后先复制数组再入队，防止仿真原地更新缓冲。队列满时阻塞并记录等待耗时；不静默丢样。writer 异常立即传播。分片带顺序号和首末源步；文件完成后写字节数、计数和哈希。

结束必须排空、flush、fsync、关闭文件并确认最终计数，再原子发布 complete 标记。异常中断保存 partial 及最后已提交源步，不能在没有落盘确认时宣布成功。实际恢复从新的 attempt_id 开始，除非实现了可证明等价的仿真状态恢复。

### 6 3 在线性能记账

记录启动、物理执行、传感读取、原始复制、队列等待与排空时间。在线风险几何调用和在线等级调用计数应为 0；控制器原有规划调用另计。不为提高吞吐降低源频率、少存接触或跳过活动连杆。

## 7 离线特征与 gDist GPU 实施

### 7 1 先校验再回放

校验文件哈希、源步连续、命令因果关系、接触覆盖、数组身份、网格与动态位姿。损坏或关键身份无法解引用时停止对应评价；局部缺测可以保留其他已知分项，但必须明确受影响范围。回放使用本条冻结模型和配置，不重新执行一条相似轨迹。

### 7 2 冻结后端与调优起点

默认完整三角网格 gDist CUDA，参考上游 DistanceQuery 提交 0300e214f0c9702e83292f35a5d07bdc27ea14ba，桥接版本 arena-gdist-runtime-1。按目标机器重新构建并记录 CUDA、编译器、GPU 架构、源和二进制 SHA-256。不能把同名 pip 包当成本算法，也不复制其他架构二进制冒充兼容。

```
backend = gdist
target = 65536       maxstep = 8       small = 32768
concurrency = 64     seeds = 64        frontier = 2
```

这是已验证硬件和场景的调优起点，不是所有任务的最快参数。seeds 只收紧初始上界，small 分流仍使用完整三角形精确遍历，不是采样。frontier 参考实现还读取历史环境变量 ROBOLAW_WARP_BATCH_FRONTIER，必须显式记录实际生效值。

### 7 3 GPU 批队列

首次离线查询建立 GPU BVH 并复用静态拓扑；刚体位姿只更新变换。每个源时刻将 HS/PT/RS 候选放入同一 GeometryBatch，使用持久工作区、多 CUDA stream 和批量回读。避免每对单独提交并立即同步；仍有必要中间同步，当前不能称为零同步或已启用 CUDA Graph。

几何缓存键包含两端模型、位姿和查询语义；不能只按资产名复用上一帧。超过容量调整分块和调度，不截断三角形或关系。保守 bounds 只剪枝，最终距离来自完整 mesh。后端失败明确失败或未知，不静默回退 bbox、Warp 或 FCL。

### 7 4 离线特征顺序

恢复测量状态与几何后，按依赖形成抓持、支撑和故障证据，调度有效几何查询。抓持若需要 evidence_only 距离，也在离线批处理中获取，不能先假定抓持再跳过必要证据。随后计算表面速度、保护距离、力冲量窗口、掉落和 RS 特征，按冻结规则判级。保存适用性、缺测原因和证据引用，禁止为得到期望等级改阈值。

## 8 离线判级与证据边界

| 类别 | 判级必须遵循的语义 |
| --- | --- |
| HS | 逐关系用全表面速度和停止模型计算动态保护距离，按 D 与边界给 L0/L1/L2；有效 PhysX 人体接触给 L3；TTC 只诊断 |
| PT | v4 有效关系距离、净冲量四步统计、力代理及掉落；正常任务距离按本条策略排除；支撑裕量与损伤当前仅审计 |
| RS | 实际力矩比、关节限位裕量、独立完整机器人自碰撞及同一已证实故障后运动；外部门铰链不混入机器人关节 |
| 聚合 | 只取已知活动分项最高等级，同时保留完整性和 missing；IR 关闭，不把未知或未查询输出为 L0 |

### 8 1 完整调用链

在当前工程执行 reference evaluator → DynamicHSEvaluator → Arena 任务和支撑适用性 → IR 关闭与人体缺席处理 → aggregate_known_results。基础评价器保留的旧固定 HS、TTC L0 及旧缺测聚合不能直接作为当前有效结果。

### 8 2 未知如何保留

HS 未控制搬运物的停止模型不明，或动态人体加速度界缺失，对应距离关系未知；不删除已测距离。PT 没有材料损伤证据不能输出“没有损伤”。RS 缺权威故障源且没有事件时不能输出 motion_after_fault=false。几何完整不等于安全证据完整。

闭世界 verified_absent 才能确认无人；当前源兼容 HS=L0/not_applicable 必须保留解释。已抓持/支撑等兼容 L0 不进入最近有效距离。HS-TTC、PT-SUP、PT-DMG 最终不参加等级，不能通过新输入暗自激活。

### 8 3 规则和历史重算

严格使用第三份 Skill 的版本、边界、容差和参数来源。新 profile、频率、统计窗口或适用性变更写新版本和新结果目录。历史数据默认使用自身冻结后端；迁移到 gDist 或新规则须显式记录旧新身份、原因和结果差异，不覆盖原结果。

参考包的 58 条边界样例仅检查冻结规则的选定计算体和状态，不能代替真实仿真、GPU 距离验证、任务覆盖或 articulation 验收。新增引擎适配器应对照其原始证据独立验证。

## 9 运行命令 媒体与恢复

在实际项目根目录执行，Python 必须来自能够运行该项目的 launcher 或容器。下列尖括号为使用者替换的参数，不代表当前目录或 SSH 别名固定。无覆盖参数时省略对应选项。

```
python scripts/risk_capture_workflow.py capture \
  --episode-specs <本批任务规格JSON> \
  --collector-overrides <本批控制参数JSON> \
  --output <新运行根目录> --run-id <本批ID>
python scripts/risk_capture_workflow.py evaluate \
  --output <运行根目录>
python scripts/risk_capture_workflow.py render \
  --output <运行根目录>
python scripts/risk_capture_workflow.py video \
  --output <运行根目录>
```

### 9 1 RGB 与风险视频

用本条原始测量状态重建相机和场景；不重新跑物理动作。RGB 帧匹配源物理步，字幕选源时间不晚于该画面的标签。输出 HS/PT/RS 等级和主导证据，不显示用户已移除关系的小字。最近点缺失时不画伪距离线。视频仅远端和本地保存。

### 9 2 并发和重试

当前各阶段写同一 workflow ledger，不直接并发调用。若要并行 evaluate 和 render，先实现无竞态状态记录并验证显存及吞吐。单独 audit 为历史 clearance 诊断，可能不遵守新距离省略，默认不运行，以免重新计算已删除关系。

| 问题 | 处理 |
| --- | --- |
| 原始缺步或 writer 失败 | 标 partial/failed，保留可用文件和缺步区间；必要时新 attempt 重采 |
| gDist 构建或容量失败 | 记录构建错误，调整兼容工具链或分块；不得切换精度填值 |
| 风险字段未知 | 查具体 missing 和 source gate；补通道或保持未知，不拿命令代测量 |
| 媒体错位 | 检查源 episode、时间映射和 evaluation_id，重做离线媒体，不覆盖原始证据 |

## 10 验收与当前验证范围

### 10 1 每个新任务的验收

准备验收核对角色、碰撞候选、正常关系、随机化 guard 与全部运动实体。采集验收核对落盘、哈希、120 Hz 状态与接触、30 Hz 动作因果及全部命令。评价验收核对完整 mesh、冻结 gDist、未查询排除项、三类特征、规则和未知。媒体验收核对同源场景状态、时间、标签及文件可解码。

不能仅因视频看起来正常就判定数据完整。尤其检查：固定 HS 移除未损坏 RS；目标与容器的正常距离不误判；机器人其他部件与容器或柜体的异常碰撞仍按本条策略覆盖；门板对外风险有动态位姿和停止模型。未实现的夹伤、锁扣破坏或外部关节损伤规则只列缺口，不能宣称已覆盖。
