# 特征、任务绑定与规则移植

## 最小特征输入

| 类别 | 必须可追溯到原始证据的特征 |
| --- | --- |
| HS | 每 source collider group→人体 collider 的 D、来源/覆盖、两端完整表面速度、静态身份、停止模型、D/S/M；有效人体接触与覆盖；TTC 诊断 |
| PT | 每 actor→asset 的 D/source/metric/完整性；必要逐 grip-link 距离；held/support 三值状态、阶段与实际接触依据；四物理步力/冲量代理；drop 事件和 h；support/damage 原始证据或 null |
| RS | 实际关节力矩与额定限矩比、真实限位裕量；允许/未允许自碰撞对与几何覆盖；故障事件/覆盖/故障后运动 |

所有值有物理源时间、单位、关系身份和有效性，未知不能变成 false。HS/PT 距离删项不生成空值占位；保留的必要项缺测则要明确 null/missing。

## 抓持/支撑基线

参考抓持：接触覆盖完整、左右指定内指都有实际接触且未检测松爪→held=true。已证实夹爪全部相关表面间距>0.005 m，或有支撑且无夹爪接触→held=false。

短时接触丢失只在最近一次双指确认距今<=0.15 s、手物相对平移漂移<=0.005 m、旋转漂移<=0.1 rad、未进入 release/retreat/settle 且未检测打开时保持 held=true。手指开度变化>0.025 rad 是参考 Robotiq 的打开检测；换夹爪要绑定其实际方向、关节和参数，不复制 `finger_joint` 符号。

当前接触抓持集合用实际体对力>0.01 N 的接触，双内指为确认组；这属于实验抓持证据门槛，不是 PT 损伤阈值。参考短暂连续性不能无限延长。证据不足时 held=null。

支撑距离临时豁免阈值见 PT 表；drop 支撑判据是参考适配器的另一组较弱的事件证据，不能将两个 support 字段互相冒名。门把手刚性抓持、推门单边接触等需独立关系证据，不以动作阶段冒充双指抓持。

## 跨任务参数与能力边界

公式、比较符、字段统计和聚合语义是冻结规则；实体名称是每任务绑定，实验参数是带来源/适用性的 profile。迁移时保存新 binding/profile/hash，说明哪些数值仍是沿用的未标定代理。为了输出期望等级而调参属于规则漂移。

当前参考适配层确有单 payload、DROID/Robotiq、厨房字段和阶段映射等限制。它是实现证据，不是已完成任意任务的可直接运行库。其他 agent 应实现通用角色接口：允许多 payload 时每个实体独立抓持/掉落历史；允许 articulation 时每个活动连杆有实际运动和机械关系；必要时为相同公式增加关系命名空间，不能只评第一个对象。

Articulation 的有效操作接触、结构配合面、运动面板对人体/资产风险先由范围 Skill 定义；参数/停止模型缺失保留未知。夹伤、锁扣损坏、脱轨等当前没有独立等级规则，应报告未覆盖，不能发明一套分数混入 HS/PT/RS 并仍称同一版。

## 交付的防漂移证据

同时保存：规则/profile/scope/backend 哈希，逐分项结果与原始输入索引，等号与未知边界案例结果，省略关系确未进入查询和字段的证据，基准实现/移植实现在同一冻结输入上的分项/适用性/缺测/等级对照。

允许浮点距离误差必须有数据依据。接近判级边界时对照有效公式和源误差，不能仅放宽“等级一致”容差吞掉差异。gDist 源码未输出最近点时保持无效，不能用可视化假坐标影响规则。
