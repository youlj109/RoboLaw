# 原始证据在线，安全特征和等级离线

在线只运行任务原本必需的物理/控制与原始证据保存。距离、风险特征、抓持/掉落风险推断、HS/PT/RS 判级、风险审计、RGB 渲染及风险视频全部离线。IR 保持关闭。

## 先绑定，再采集

读取本任务的场景、机器人、关节图、动态资产和规则清单。不要固定人体、瓶子、碗、场景 ID、单一 payload、人体数量或厨房连杆清单。

按 [原始证据契约](references/raw-evidence.md) 明确每项特征来自哪个原始通道，按 [任务适配](references/task-adapters.md) 补齐 articulation/多物体/动态人体。若可用，先用 `$robot-risk-asset-scope` 明确关系范围；未安装也必须冻结本条清单和正常任务关系。

将每条数据的规则、参数/单位、资产角色、网格哈希、完整仿射与刚体坐标、相机、排除、控制时钟和后端身份冻结，独立生成摘要。必要数据缺失应记录未知/不支持，而不是编造零值或沿用旧场景。

## 在线阶段

- 基准为 120 Hz 物理原始状态、30 Hz 实际动作/观测。该版本 PT 冲量用四个物理步的窗口；改变时钟须改显式版本和统计口径，不能悄悄重采样。
- 在实际动作提交前记录测量观测及其物理源时间，记录真实提交目标/动作、命令异常；不要拿名义命令替代实际提交。
- 保存真实状态、逐步接触身份与点数据、限位/额定值、实际 COM 运动和重建快照；有界异步写入，过载时阻塞并记录，不丢帧，结束排空并 fsync。
- 明确省略的 HS 接触在提取点数据前过滤；其余必要证据按各自规则保留。HS 固定结构删除不得损坏 RS 独立机器人几何。
- 只冻结 CPU 原始网格，不创建用于风险查询的 GPU BVH、不运行 gDist 风险查询，不提取风险特征或给 L 等级。记录这些调用计数应为 0。
- 规划器完成任务本来就需要的状态/碰撞计算仍可在线执行；单独记录其用途和实际控制输入，不能假称整个仿真没有碰撞计算。未来视觉策略的实际在线图像输入必须在线保存，不能以后渲染代替。
- 原始结束状态为 `pending_offline`，不因任务成功标为安全通过。

## 离线阶段

1. 校验原始时钟、步数、文件/hash、actor 路径和命令/观测对齐。只读源归档。
2. 用本条冻结网格和本时刻测量位姿重建 HS/PT/RS。历史数据按其冻结后端与规则回放；显式迁移写入新目录并保存源/目标身份。
3. 按 [gDist 后端](references/gdist-runtime.md) 在 GPU 批量计算完整 mesh 距离/相交；在提交前排除省略项，不生成它们的距离字段。对已授权的正常支撑面整关系排除，连机械臂/夹爪及搬运物→该表面的 PT 力/冲量风险汇总、表面速度和规则都不提取；不能只在最后聚合时隐藏等级。共享原始抓持/支撑证据按自身用途保留，见 [原始证据契约](references/raw-evidence.md)。
4. 离线汇总逐物理步接触、抓持连续性、支撑、掉落候选、COM 表面速度、TTC、关节裕量、力矩比、故障后运动。不得把任务阶段直接当抓持或支撑真值。
   按 2026-10-27 明确夹持接触授权，声明的夹持部件→任务搬运目标物不生成 PT 力/冲量风险汇总和规则；原始接触及抓持所需的冲量/力诊断仍可使用。冻结版本 `robolaw-grip-target-contact-exclusion-1`，不能把此规则扩大到其他部件/资产或改写旧 episode。
5. 按冻结规则逐条判级，再聚合已知分项最大等级；覆盖、未知、不适用独立输出。若可用，使用 `$robot-risk-hs-pt-rs-rules`，不在此处另造阈值。
6. 输出 `offline_replay` 的特征、分项、HS/PT/RS、缺测原因、适用性、主导关系、后端参数和分阶段物理耗时。原始任务成功与风险等级分开。
7. 按源测量状态离线渲染 RGB，再叠加源时间不晚于 RGB 的风险标签。校验所有帧、时间、任务身份；仅按约定在本地/运行主机保存视频，不默认上传 Git/模型库。

## 完整网格与性能边界

使用冻结的 gDist 作者算法和项目已调优的持久 BVH、共享 HS/PT/RS 队列、跨对象并发 CUDA 流、精确小网格分流、保守候选剪枝。复用 [参考构建包](assets/gdist-reference/SOURCE_NOTICE.md)，不要仅安装同名 Python `gdist` 包（其可能是别的算法）。

目标是缩短相同输入、相同规则、相同距离口径的端到端耗时，不是制造 GPU 100% 占用。本机参数是调优起点，不是所有 GPU/场景的全局最优保证。禁止以 bbox/SDF/采样替代距离、降低频率、丢关系或改阈值来冒充性能改进。

## 完成条件

交付原始契约与本条冻结清单、在线零风险调用记录、离线结果、时间对齐视频及阶段耗时。新场景至少独立证明原始证据可重建、保留关系有真实网格结果、缺测诚实保留。尚未适配的 articulation、形变、动态人体要明确能力边界，不能用旧厨房成功代替。

接入现有仓库时阅读 [RoboLaw 入口映射](references/robolaw-entrypoints.md)；其他 agent 不需要 SSH 别名或绝对路径即可按契约实现。
