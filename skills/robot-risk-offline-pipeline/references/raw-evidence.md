# 在线原始证据与离线特征契约

## 冻结清单

每条 episode 包含 task/scene/robot/object 身份及版本、随机种子与允许范围、角色和关系清单、适用/省略策略、动作阶段映射、关节图/传动和刚体清单、碰撞网格顶点/面与哈希、完整缩放/剪切/父变换、世界/局部坐标及四元数约定、相机内外参、物理设置、规则/profile/参数与代码哈希、gDist 源提交/构建/架构/编译器/二进制哈希。

2026-10-26 正常支撑面授权使用 `robolaw-normal-support-exclusion-1` 冻结。运动机械臂/夹爪、搬运物与明确正常支撑面的被删 PT 关系，在离线特征循环前移除，不查询/保存距离，也不生成该关系的接触力/冲量风险汇总或等级。只要抓持、支撑、RS 或重建仍需共享原始接触/状态，仍在线保存其必要证据；不要把“删除风险特征”错误实现为破坏原始证据覆盖。其他正常接触和其他对象按各自冻结范围处理。

2026-10-27 夹持目标物接触授权使用 `robolaw-grip-target-contact-exclusion-1` 冻结：确切夹持部件→本任务 payload 的 PT 力及同源冲量风险特征/规则省略，抓持所需的原始点冲量、双指接触及诊断保留。不得把缺少 held=true 当成取消豁免的理由；其他机器人部件、外部资产及掉落判定仍按自身范围处理。历史无此声明的 episode 保持原义。

冻结配置中的说明不能替代实际几何和可重建的状态；路径不能替代 mesh 内容。每个三角形要能恢复到本时刻世界坐标。原始网格可以按哈希去重；记录实例到几何及刚体的关系。

## 原始数据 → 离线特征

| 在线保存 | 离线得到 | 缺少时 |
| --- | --- | --- |
| 机器人各刚体 actor 位姿、COM 世界位置、COM 线速度、世界角速度 | 真实网格位置、全表面速度界、HS 动态保护距离、RS 自碰撞 | 对应关系未知；不能拿 TCP 速度代替全部部件 |
| payload/运动障碍/人体/关节资产各活动连杆同类原始运动通道 | HS/PT 距离、被驱动连杆对外风险、速度与停止模型输入 | 不能把移动对象冻结在初始位置 |
| 机器人 q、dq、实际施加关节力矩、关节限位、额定/运行限矩与关节身份顺序 | RS 限位裕量、力矩比、故障后运动 | 未知；控制目标不等于实际力矩 |
| 关节资产各 joint 的 q/dq/轴/类型/限位/父子关系、实际驱动目标/力矩（若存在）及逐连杆位姿 | articulation 几何重建、机械状态诊断、正常结构关系 | 只有根位姿不能恢复开门/抽屉状态 |
| 每物理步真实 actor0/1、collider0/1、点位置、法向、冲量向量、分离量、事件时钟和订阅覆盖 | 人体接触、PT 力/冲量、支撑/双指接触、有效碰撞 | 无报告且无完整订阅覆盖不能当“无接触” |
| 原始手指关节位置、手/物体位姿、源时间接触 | 双指接触、短时接触丢失连续性、相对位姿漂移、脱离/松爪 | 不能只凭 close/lift/place 阶段设 held=true |
| payload 世界位置/速度和原始接触 | 支撑、失持、下降/掉落候选、下落高度 | 无损伤传感器不能由掉落推导“已破碎” |
| 故障状态覆盖、具体故障码/命令写异常/无效遥测事件、关节状态和时钟 | 故障后运动证据 | 没有异常日志不能当权威健康状态 |
| 质量/COM/接触几何、支撑面定义、损伤原始传感器（若有） | 可选支撑裕量/损伤证据 | 缺测保留未知，当前冻结规则中这两项仍为审计项 |
| 动作前测量观测、原始任务信号、实际提交命令/动作、阶段/动作序号、时间映射 | 因果离线回放、风险/画面对齐 | 禁用未来状态回填当前帧 |
| 渲染所需实际机器人、物体、厨房/场景关节、灯光、材料、相机状态 | RGB 和风险视频 | 后渲染 RGB 不冒充实际在线视觉策略输入 |

`get_transforms()` 的 actor 原点不等于 COM。必须保存 COM 世界位置并与 COM 线速度配对；不能用 actor 原点拼接 COM 速度。

单位使用 m、s、rad、N、N·s、N·m，并声明四元数顺序（参考实现为 xyzw）。每个数组有稳定路径/名称到行索引映射，跨环境也不能凭顺序猜测。

## 时钟和写入

- 参考物理频率 120 Hz、动作/观测/标签 30 Hz。每个风险窗口是连续四个物理步，标签有 source_physics_step 和评价完成时间，二者不是一个时钟。
- 动作前 observation[t] 对齐实际 action[t] 前的已完成物理状态。初始化状态使用明确的初始序号，不能伪造四步接触覆盖。
- 原始流采用有界异步队列和独立 writer；复制数据后入队，防止数组继续被仿真原地更新。结束排空、fsync、存流哈希及计数；writer 异常或缺步明确失败。
- 非有限值转 null 并有 validity/missing 标记，不默认为零。无落盘确认不能称采集完成。

## 禁止在线运行的风险工作

机器人/物体/人体风险距离、风险最近点、碰撞下界作为风险特征、D−S/SSM、TTC、接触力/冲量风险窗口汇总、风险用抓持/支撑/掉落分类、自碰撞风险几何、限位裕量/力矩比风险计算、HS/PT/RS 判级、完整审计、RGB/视频导出。

CPU 网格冻结、读取 COM 原始遥测、原始接触复制、元数据绑定属于采集必要工作。控制器为做动作必需的规划/状态仍在线，但风险采集器不可借此附带运行整套风险评价。

## 范围省略与共享数据

已授权不计算/保存的 HS 资产在构建风险 mesh 前跳过。精确身份的休闲服接触或固定结构→人体接触，可在读点位置/法线/冲量之前跳过。没有接触身份不能猜测过滤。

距离-only 的 PT 省略不自动过滤原始接触，因为力/冲量/掉落或抓持可能仍要用。RS/PT/控制/渲染需要的共享状态与独立几何保持完整，不能为 HS 删减而破坏其他类别。保存一次策略与溯源，不逐帧输出被省略关系的距离值、下界或伪 L0。
