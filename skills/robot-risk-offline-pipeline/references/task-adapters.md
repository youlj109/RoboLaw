# 跨任务适配与能力边界

## 通用契约

先实现 engine_adapter → raw_episode → offline_features → frozen_rules → media 的边界。agent 可以换仿真引擎、目录和机器人，但不能换字段语义、单位、时钟、规则边界或未知策略。角色到完整路径的映射来自每个任务配置，不从旧场景变量名推断。

| 场景变化 | 必须补齐 |
| --- | --- |
| 多机器人/双臂/多 payload | 每个 actor/link 和任务关系身份、全部 COM 与实际动作；不要只存第一个物体 |
| 其他 pick-and-place | 本任务物体/容器/支撑面、抓持部件与开闭方向、正常阶段、停止模型/对象阈值适用性 |
| 开门/抽屉 articulation | 活动连杆逐物理步位姿/COM 运动，joint q/dq/轴/限位/父子、真实驱动和接触、固定基体；正常配合面与外部碰撞分开 |
| 活动面板对人体的风险 | 把面板绑定为关联运动源；受机器人控制的停止假设须证明适用，否则对应动态关系未知 |
| 动态刚体人体 | 实际 COM 运动、受保护表面、明确的人体加速度界；当前冻结 profile 未给该界，不能默认静止 |
| 骨骼/形变人体或软体 | 可重建的每时刻顶点/骨骼与 skinning/形变参数和一致表面速度；旧刚体通道不足，明确未支持 |
| 移动基座或更换机器人 | 不再按名字免除 base；重做刚体/关节图、限位/限矩/结构相邻对和运动表面 |

新任务不能直接执行参考适配器中的 `row['mustard']`、`base_link`、`finger_joint` 或固定厨房 link 列表并声称通用。应通过任务映射抽象这些字段；保留原始路径/单位与冻结摘要。没有必要数据时补采或保持未知，不能在离线按命令轨迹预测并冒充测量真值。

## Articulation 原始频率

逐活动连杆位姿/COM 运动按 120 Hz 保存，或保存能在物理步精确重建的实际 joint 状态和冻结运动学，并说明时钟。原有厨房用于 RGB 的 30 Hz 连杆位姿只保证其原用途，不自动满足任意快速关节资产的物理步风险重建。风险计算仍为离线 30 Hz，接触仍保留每物理步。

机器人关节力矩规则不能不经定义地套到外部门铰链。外部关节损坏、夹伤或锁扣破坏若没有当前版本的判级规则，只能作为原始证据/诊断和覆盖缺口；新增分项另立版本。

## 新任务完成状态

区分“接口已写”“组件能运行”“完整轨迹原始证据齐全”“离线规则完成”“真实风险证据完整”“视频对齐”和“任务成功”。只有本任务的完整数据能支撑其对应声明。当前厨房已有完整案例，不代表 articulation 已经过同等运行验证。
