# 三份机器人风险 Skill

## 分工

| Skill 目录 | 职责 |
| --- | --- |
| `robot-risk-asset-scope` | HS/PT 资产角色、可能碰撞范围、任务正常关系与省略策略 |
| `robot-risk-offline-pipeline` | 必要原始数据在线采集，gDist GPU 完整网格与安全特征/等级/媒体离线处理 |
| `robot-risk-hs-pt-rs-rules` | HS 动态距离、PT v4、RS、未知/适用性与已知结果聚合的冻结规则 |

建议三份一起使用，也可按职责单独选用。单独使用时仍需本任务的冻结规则或原始证据，不能因为另一份 Skill 未加载就自行补造。

## 给其他 agent

复制这三个完整目录，不要只复制 SKILL.md：references、assets、scripts 和 agents 元数据都应保留。

Codex 可放到 `~/.codex/skills/`；其他 agent 放入其支持的 Skill 目录，或显式让它读取各目录的 SKILL.md，再按正文按需读取引用。文档没有依赖本机 SSH 别名、主机路径或某个云端连接器。

示例请求：

> 请读取并执行这三份 Skill：robot-risk-asset-scope、robot-risk-offline-pipeline、robot-risk-hs-pt-rs-rules。为本次任务建立独立资产/关系/规则绑定，实现必要原始证据在线保存、风险和 RGB/视频离线处理。任务是开抽屉/开门/搬运物体时，分别补齐活动连杆、正常操作关系及原始运动通道。保持冻结公式和边界，不照抄芥末瓶场景 ID 或排除清单；不能重建或没有停止模型/损伤/权威故障证据的部分保留未知。交付本任务的范围清单、数据契约、逐分项判级与覆盖、后端身份和阶段耗时。规则扩展单列新版本与差异。

## 文件与复现

- 第一份包含通用角色绑定示例，以及单独标记 example_only 的当前厨房配置，用于复现已确认的 90 对 HS、81 项 PT 距离省略。后者不能迁移为所有任务默认清单。
- 第二份包含原生 gDist 桥接、补丁、构建器、Python 后端及 GeometryBatch。固定作者提交在构建时取得；包中没有二进制和完整仿真器。新机器要按其 CUDA/架构构建，参数需按其工作负载实测。
- 第三份包含完整公式/边界、规则锁、58 个边界与缺测案例，以及有效包装链的源文件快照与 SHA-256。`python robot-risk-hs-pt-rs-rules/scripts/verify_rule_examples.py` 无需 GPU/仿真器，只核对冻结规则案例，不验收新任务实现。
- 实际采集、离线评价和可视化依赖目标工程的仿真、控制和渲染适配，不是解压后自动启动机器人或提交代码。

## 已完成的检查与边界

三份 Skill 通过 skill-creator 的格式检查；58 个案例对照冻结源定义全部通过。当前厨房已实际运行完整 2,292 帧数据与对齐视频；其他 pick-and-place/articulation 的通用契约已经写入，但没有因此宣称那些新场景已经实测通过。

当前项目参数为实验候选，不是普适 ISO 数值或已标定物理性能。gDist 只有完整三角表面距离及碰撞体身份，当前没有最近点坐标；不能补零点画距离线。缺测与几何完整、L0 与全部证据完整都要分开报告。

此包不含密码、Token、SSH 私钥、视频或大型场景资产；RoboLaw 自有贡献的许可和上游归属保留在源快照目录。
