# 正常任务关系

## Pick-and-place

1. 将 object、goal_container、support_surface、robot_grip_links 绑定为本任务具体身份。支持多个目标物/机器人/容器，代码不固定 mustard/bowl。
2. 目标物进入指定容器本来就是目标：目标物→该容器的正常接近距离不作为 PT 风险。明确所有任务阶段排除还是仅在定义阶段生效，并冻结授权。
3. **正常支撑面整关系排除（2026-10-26）**：物体原本放在台面上、机器人必须接近该表面完成抓放时，将本任务运动机械臂/夹爪→已绑定正常支撑表面、搬运物→同一表面，声明为 `all_PT_features_and_rules` 排除。提交 GPU 前移除对应查询目标；不计算、不保存这些关系的风险距离、最近点、速度、接触力/冲量风险汇总，不生成分项等级或伪 L0。该授权不是仅删除距离规则。当前范围版本为 `robolaw-normal-support-exclusion-1`。
   必须由当前任务的 on/预期支撑关系和实际碰撞体身份绑定，不能因“看起来像桌子”删除任意台面、柜体、墙或地板。支撑表面与柜体侧面/门板共用不可区分网格时先拆分/明确覆盖边界，不能悄悄免除整个柜体。多阶段任务按实际允许范围声明阶段；本次香蕉案例明确为全任务阶段。
4. 机器人→目标物正常抓持距离按部件和阶段处理。抓持判断仍需距离时保留 evidence-only 查询；不能依赖它确认脱离却宣称完全不计算。2026-10-27 用户另行授权：明确绑定的夹持部件→本任务搬运目标物，不进行 PT 接触力或同源冲量判级；冻结 `normal_grip_contact_exemption`，版本 `robolaw-grip-target-contact-exclusion-1`，范围 `declared_grip_parts_to_task_payload_all_phases`，`grade_force=false`、`grade_impulse=false`。不要求先证明 held=true，避免用被豁免接触先判危险再确认抓持。保留必要原始接触、双指证据和抓持诊断，不输出这类关系的 PT 力/冲量风险汇总、规则或伪 L0；机械臂非夹持部件→目标物、夹爪→其他资产仍保留。该接触授权不改变既有距离适用性或目标物掉落检测，也不自动扩展到 articulation 把手。
5. 机器人→容器是否豁免、是否整项 PT 不适用，是单独的任务/用户决定；不能从“物体要放进碗里”推导所有机器人撞碗都无风险。
6. 第 3 条是用户明确的整关系 PT 排除，优先于原先“距离排除、力/冲量保留”的默认行为。其他距离豁免仍不自动免除异常冲击、力、冲量。正常支撑关系删除不取消目标物其他时刻的掉落检测，不改变 HS 或 RS；抓持、支撑、重建仍需要的共享原始接触/状态/几何可保留，但不得另存被删关系的风险特征。

原生任务接入时按任务逐一解析支撑角色，不能只改香蕉场景 ID。没有这种正常支撑关系的 articulation 任务不凭空添加排除，也不因此删除门板、铰链或外部碰撞风险。历史标签不覆盖；按新范围重新计算须单独输出并记录迁移。

若按测量支撑临时豁免，至少需要已声明关系、阶段、完整真实接触、接触位于物体下方、法向接近支撑方向、浅穿透和低速证据；不能仅凭阶段名或距离零认定有支撑。具体阈值从冻结 profile 读取。

## Articulation：开门、开抽屉、拨杆

建立“固定基体—关节—运动连杆—把手/接触面—限位/闭合面—外部障碍”的任务图。

| 关系 | 范围处理 |
| --- | --- |
| 手指/夹爪 → 已绑定把手或操作面 | 正常操作距离可豁免，保留抓持证据和未豁免的力/冲量 |
| 机械臂其他部位 → 门板/柜体边缘 | 若可接近/碰撞则保留，不按整个资产任务角色全部排除 |
| 门板/抽屉 → 人体/外部资产 | 纳入关联运动体候选，保存逐连杆运动；停止模型不足保持未知 |
| 同一固定刚体内表面、铰链/滑轨设计配合面 | 精确到结构对排除不合理零间距，不扩大到非相邻连杆 |
| 门/抽屉 → 设计闭合面或止挡 | 按任务和结构声明正常距离，异常冲击、关节过限独立处理 |
| 活动部件 → 外部桌面/墙/设备 | 除非证明超出运动/警戒包络或用户明确缩小范围，否则保留 |

不要把整个 articulation 资产当静态网格。活动连杆要有本条数据自己的变换，与风险时刻对齐。面板/铰链关节力矩、速度、锁扣状态不是机器人关节数据的别名。

冻结规则没有独立“夹伤、锁扣破坏、铰链损坏、抽屉脱轨”的判级表。可采必要原始信号并记录诊断，但不能擅自发明 L 等级还声称同一版规则；新增规则要有显式版本和参数来源。
