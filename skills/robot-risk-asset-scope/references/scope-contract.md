# 资产范围与碰撞候选契约

## 身份和几何

每个资产至少记录：稳定 asset_id、语义角色、完整 prim/actor/link/collider 路径、实际碰撞网格哈希、局部坐标与单位、刚体/固定/关节/形变类型、动态状态来源、所属人体/机器人/任务对象。同名叶节点不能替代唯一完整路径。

距离以真实参与规则的 authored 碰撞表面为准。不要把外观模型、物体中心或可视 bbox 当成最终网格距离。完整仿射缩放/剪切烘焙进顶点，运行时位姿提供刚性变换；基础曲面三角化记录分辨率和误差。此口径不等于 PhysX 烹制后的凸体、实体穿透深度或材料损伤。

## 关系图

| 字段 | 含义 |
| --- | --- |
| relation_id / actor / object_id | 唯一关系、方向和两端身份 |
| category / rule_ids | HS 或 PT，以及具体受影响分项 |
| role / active_phases | 搬运、抓取、放置、支撑、操作、运输等语义 |
| query_distance / persist_distance | 是否实际查询、是否写距离；省略时两者均 false |
| evidence_only | 距离不判级但为抓持等提供必要证据 |
| grade_distance / grade_contact / grade_force / grade_impulse | 独立适用性，禁止一项豁免扩散到全部规则 |
| acquisition_omission | 是否连对应风险接触点等也不提取保存；不是距离豁免的隐含行为 |
| reason / authorization / evidence | 用户指示、正常任务关系或保守几何证据 |
| guards | 场景/任务/角色/动作边界/拓扑/几何/随机化约束 |
| version / hash | 实际生效清单的冻结版本与摘要 |

`query_distance=true, grade_distance=false, evidence_only=true` 用于必要抓持证据，不属于“完全不计算”。若需完全停止查询，须另有能支撑抓持/脱离判断的原始证据，或明确相应分项未知。

`robolaw-normal-support-exclusion-1` 是明确的整关系 PT 排除：`extract_risk_features=false`，距离/接触力/冲量风险查询、字段和规则均不生成；不以 null 或 L0 占位。在一次性 omitted 清单保留精确源、被排除碰撞表面、任务/hash、授权和阶段。混合目标关系只减去获授权的表面，其他碰撞体继续评价；不要删除共享原始支撑/抓持证据。

## 仅保留可能碰撞的候选

“可能碰撞”使用完整运行范围：机器人所有活动表面、夹爪张合、搬运物外伸、被操纵连杆扫掠、关节/控制误差与允许随机化。门板打开、抽屉滑出、机械臂撤回也属于运行范围。机械臂够不到而搬运物够得到的资产不能排除。

可用两级选择：

1. 场景准备时以已声明的可达/运动包络选择潜在候选；不能证明不相交的保留。此步骤不在在线物理采集循环中运行风险测距。
2. 离线使用本条完整已记录轨迹和误差包络，保守证明部分对不可能相交；留下证据与有效范围，再跳过窄相查询。若用于预警距离，还须把保护距离上界纳入包络，不能只证明没有接触而漏掉 L1/L2 接近。

保守 AABB/BVH 只能做候选裁剪。下界不能作为“已测得距离”保存或交给规则；数值距离仍来自完整 mesh 的 gDist。几何接触不可能与“没有接近风险”是不同命题。

对象动态、可被推移、门板可开合、人体可运动或轨迹范围不完整时，不能凭初始摆放省略。只有明确用户缩小评价范围、明确正常任务关系或完整包络证据时才移出。用户选择是范围决策，不能宣传成普遍的碰撞不可能事实。

## 固定结构与人体覆盖

固定基座由实际刚体和关节图绑定。`base_link` 可能是随动夹爪、移动底盘或其他结构，不得按名字识别固定支座。会移动的基座不是固定结构豁免。

人体清单以本场景加载并启用的保护表面为准，人数和网格数不限。重复外壳/衣物能否移除要有覆盖依据，避免移除某身体区域唯一的表面；不确定时报告覆盖缺口。原始接触与网格测距清单一致处理明确排除项。

HS 固定结构数据移除在查询构建之前完成，同时删除固定分项/相交审计；RS 独立保留完整机器人几何。仅距离判级豁免而保留测量应使用不同策略，不能混称为“已删除”。

## 采集、离线、随机化

采集只读取并冻结角色、表面与必要状态，不运行风险距离或等级。离线筛选要有足够源几何和实际位姿；不能为了省存储先删掉后来筛选所需的证据。

每条数据的查询集合、排除依据与过滤参数应可重建。不能只匹配场景 ID：还检查角色、机器人身份、网格哈希/拓扑、关节图、允许动作和随机化边界。不匹配则重新解析，不沿用旧 37/81/90 等数字。

人可读结果列出剩余资产与关系。未查询、未知、不适用、禁用、已知 L0 是不同状态。
