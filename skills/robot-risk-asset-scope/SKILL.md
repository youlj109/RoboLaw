# HS/PT 资产与关系范围

将场景解释为任务角色、碰撞表面和关系图，输出可冻结的资产范围。不要把当前厨房资产名、人体网格数或历史排除清单变成所有场景的默认值。

## 工作方式

1. 读取本任务规格、完整资产拓扑、机器人刚体/关节图、允许动作和随机化范围。绑定机器人运动部件、固定结构、人体、搬运物、放置容器、预期支撑面、articulation 运动连杆/把手/固定柜体等角色。
2. 按 [范围契约](references/scope-contract.md) 建立有向关系；以机器人及其驱动物件在运行中的可能碰撞范围选择候选。历史 L0、初始距离远、对象名称、仅一条成功轨迹，都不是“永不碰撞”的证明。
3. 读取 [正常任务关系](references/task-relations.md)。将“不要计算距离”“距离不判级但仍为抓持提供证据”“整项 PT 关系不适用”“HS 整个资产不采相关风险数据”分开声明。
4. 原始采集前冻结已知身份、角色和排除策略；需要本条实际轨迹才能确定的保守剪枝，在离线完成。不要为选候选把风险测距或风险特征计算搬回在线采集循环。
5. 使用 [任务绑定示例](assets/task-scope.examples.json) 的结构生成本任务清单，不照抄其中示例 ID。输出 included、omitted、unresolved 三类关系、依据和具体计算/保存边界。未解析项不能被悄悄当作安全排除。

## 必须保留的语义

- HS：机器人运动部件、末端和与机器人关联的搬运物到人体受保护表面的距离。主动操纵的门板/抽屉可能碰人时也应列为待绑定的关联运动体；缺少其运动或停止模型时保留覆盖缺口，不能假装瓶子模型已经支持。
- PT：机器人及搬运物/被驱动物件到可能被撞坏的资产；既考虑机器人直接碰撞，也考虑携带物或运动面板撞到其他资产。
- 正常放置：目标物→目标容器的距离按任务声明排除。2026-10-26 用户明确要求：抓取放置中已确认的正常支撑台面，运动机械臂/夹爪→该表面、该任务搬运物→该表面，不提取 PT 距离、接触力/冲量风险特征，也不生成 PT 规则；按 [正常任务关系](references/task-relations.md) 精确绑定和冻结整关系排除。其他距离豁免不自动扩大到力/冲量。
- 正常抓取/操作：夹爪→被抓目标、手指→把手、结构相邻件的设计接触，按确切部件和任务阶段声明。不能豁免整条机械臂到整个柜体的所有关系。
- 2026-10-27 夹持目标接触授权：将本任务明确绑定的夹持部件→搬运目标物的力与同源冲量从 PT 判级中排除，冻结 `robolaw-grip-target-contact-exclusion-1`；抓持原始接触及其必要证据继续保留。详见正常任务关系，不扩展到机械臂其他部位、目标容器、外部障碍或 articulation 把手。
- HS 移除的固定底座，不等于从 RS、自碰撞、PT 或重建场景中删除该结构。衣物只有经明确授权并确认保护表面覆盖安排后才可排除；不要对所有任务自动删除全部衣物。
- 省略关系在提交 GPU 查询前移除，也不保存对应风险距离、下界、最近点或伪 L0；允许只保存一次排除策略和溯源。其他规则需要的共享状态/几何仍按自己的范围保存。
- 每条随机化数据使用自己的拓扑、几何、位姿、角色和豁免；资产、动作边界或支撑关系改变时重新解析范围。

## 输出与验收

交付 `asset_inventory`、`relation_scope`、`task_relations`、`coverage`、`scope_hash` 及人可读说明。清单字段见范围契约。

可应用户要求逐项在原场景高亮资产、显示名称与关系；定位框/引线不冒充网格最近点或实际距离线。检查删除项没有进入查询计划或距离字段；保留项覆盖与未知单独报告。

复现 RoboLaw 2026-10-23 案例时才读取 [当前场景快照](references/current-scene.md) 与 [实际配置快照](assets/current-scene-scope.json)。它是带用户授权的特例，不是新任务的排除模板。

本 Skill 只决定范围，不改等级阈值。需要判级时使用任务冻结规则；若可用，配合 `$robot-risk-hs-pt-rs-rules`。采集边界可配合 `$robot-risk-offline-pipeline`，未安装其他 Skill 时也不得凭空发明规则或原始证据。
